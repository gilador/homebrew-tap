# gilador/homebrew-tap

Homebrew casks for [gas](https://github.com/gilador/gas): Claude, Codex and Grok plan limits in the macOS menu bar.

```bash
brew install --cask gilador/tap/gas
```

gas is not notarized, so the first launch asks you to confirm it in **System Settings → Privacy & Security → Open Anyway**. gas updates itself; `brew upgrade` is not needed.

The cask is updated automatically by gas's release script.
